# 📚 DSA — Data Structures & Algorithms in Java

Implementações de algoritmos e estruturas de dados clássicos em Java, com comentários explicativos para facilitar o entendimento.

## 🎯 Objetivo

Servir como referência prática para estudo de DSA, cobrindo desde o básico até tópicos mais avançados. Contribuições e sugestões são bem-vindas!

## 📂 Conteúdo

O repositório está organizado no diretório `src/` e cobre tópicos como:

- **Estruturas de Dados**: Linked Lists, Stacks, Queues, Trees, Hash Tables
- **Algoritmos de Ordenação**: Bubble Sort, Merge Sort, Quick Sort, etc.
- **Algoritmos de Busca**: Binary Search, Linear Search
- **Grafos**: BFS, DFS, caminhos mínimos
- **Recursão e Programação Dinâmica**

> *Consulte o diretório `src/` para ver todos os arquivos organizados por tema.*

## 🚀 Como executar

**Pré-requisitos:** Java 11+ e uma IDE como IntelliJ IDEA (recomendado).

```bash
# Clone o repositório
git clone https://github.com/silversurfer8080/DSA.git

# Abra no IntelliJ IDEA e execute qualquer classe com método main
```

## 🤝 Contribuindo

1. Faça um fork do projeto
2. Crie uma branch para sua feature (`git checkout -b feature/novo-algoritmo`)
3. Commit suas mudanças (`git commit -m 'Adiciona implementação de Dijkstra'`)
4. Push para a branch (`git push origin feature/novo-algoritmo`)
5. Abra um Pull Request
